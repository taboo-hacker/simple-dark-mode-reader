# Simple Dark Mode & Reader

一个轻量级的 Chrome 浏览器扩展，提供一键深色模式、阅读模式和字体大小调节功能，同时记忆用户设置。

## 功能特性

- **深色模式**：一键开启/关闭网页深色模式，保护眼睛
- **阅读模式**：净化网页内容，隐藏广告和干扰元素
- **字体大小调节**：可调节网页字体大小，提高阅读舒适度
- **设置记忆**：自动保存用户设置，下次打开浏览器时保持一致
- **AdGuard 集成**：检测 AdGuard 是否安装并运行，打开 AdGuard 助手，监听 AdGuard 拦截事件，与 AdGuard 共享过滤状态

### 本地开发安装

1. 下载或克隆本项目到本地
2. 打开 Chrome 浏览器，进入 `chrome://extensions/`
3. 开启右上角的「开发者模式」
4. 点击「加载已解压的扩展程序」
5. 选择本项目的根目录
6. 扩展已成功安装，可在浏览器工具栏看到扩展图标

## 技术实现

- 使用 Chrome Extension Manifest V3
- 利用 Chrome Extension APIs：`scripting`、`storage`、`tabs`
- 通过 CSS 注入实现深色模式和阅读模式
- 使用 Chrome 存储 API 持久化用户设置
- 响应式弹出界面设计

## 权限说明

- `activeTab`：获取当前活动标签页的访问权限
- `scripting`：注入脚本和 CSS 到网页
- `storage`：存储用户设置
- `<all_urls>`：允许在所有网页上运行扩展

## 如何使用

1. 点击浏览器工具栏中的扩展图标打开弹出界面
2. 切换「深色模式」开关开启/关闭深色模式
3. 切换「阅读模式」开关开启/关闭阅读模式
4. 使用「字体大小」滑块调节网页字体大小
5. 设置会自动保存，下次打开浏览器时保持一致
6. **AdGuard 集成**：
   - 查看 AdGuard 安装状态和运行状态
   - 点击「打开 AdGuard 助手」按钮启动 AdGuard 助手
   - 扩展会自动监听 AdGuard 拦截事件
   - 与 AdGuard 共享过滤状态
