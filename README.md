# Simple Dark Mode & Reader

一个轻量级的 Chrome 浏览器扩展，提供一键深色模式、阅读模式和字体大小调节功能，同时记忆用户设置。

## 功能特性

- **深色模式**：一键开启/关闭网页深色模式，保护眼睛
- **阅读模式**：净化网页内容，隐藏广告和干扰元素
- **字体大小调节**：可调节网页字体大小，提高阅读舒适度
- **设置记忆**：自动保存用户设置，下次打开浏览器时保持一致
- **AdGuard 集成**：检测 AdGuard 是否安装并运行，打开 AdGuard 助手，监听 AdGuard 拦截事件，与 AdGuard 共享过滤状态

### 高级功能

- **智能去水印**：自动隐藏常见网站的水印、版权标签，提供更干净的阅读体验
- **网页净化**：移除弹窗、推广内容、登录遮罩等干扰元素，让网页更加清爽
- **强制复制**：解除网站禁止复制、禁止右键的限制，自由复制网页内容
- **视频增强**：为网页视频添加倍速控制、全屏和画中画功能，提升视频观看体验
- **滚动平滑**：开启平滑滚动效果，支持自动阅读模式，减少眼睛疲劳
- **夜间模式增强**：智能识别网页主题色，提供更舒适的深色体验

### 本地开发安装

1. 下载或克隆本项目到本地
2. 打开 Chrome 浏览器，进入 `chrome://extensions/`
3. 开启右上角的「开发者模式」
4. 点击「加载已解压的扩展程序」
5. 选择本项目的根目录
6. 扩展已成功安装，可在浏览器工具栏看到扩展图标

## 技术实现

- 使用 Chrome Extension Manifest V3
- 利用 Chrome Extension APIs：`scripting`、`storage`、`tabs`
- 通过 CSS 注入实现深色模式和阅读模式
- 使用 Chrome 存储 API 持久化用户设置
- 响应式弹出界面设计

## 深色模式优化

### 核心逻辑重构
- **智能元素级适配**：自动识别网页所有元素（背景、文字、边框、按钮、卡片、导航栏），统一适配深色主题
- **彻底解决黑底白块问题**：强制覆盖原网页的白色/浅色背景，将所有区块统一为深色
- **智能主题识别**：自动检测网页原生深色模式，优先适配原生样式
- **分级深色模式**：提供「标准深色」「纯黑护眼」「柔和深色」3种档位
- **网站白名单**：支持用户添加不启用深色模式的网站

### 视觉与体验优化
- **平滑过渡动画**：切换深色模式时页面无闪烁，添加0.3s淡入淡出效果
- **状态记忆**：自动记忆用户在每个网站的深色模式开关状态、档位选择
- **适配特殊元素**：自动适配图片/视频区域、表单、按钮、输入框、广告栏、弹窗、遮罩层
- **护眼效果**：降低屏幕亮度、过滤蓝光，减少视觉疲劳

### 额外功能
- **一键还原**：可快速恢复网页原生样式
- **网站特定设置**：为每个网站保存独立的深色模式设置
- **系统主题适配**：适配暗黑模式系统设置

## 权限说明

- `activeTab`：获取当前活动标签页的访问权限
- `scripting`：注入脚本和 CSS 到网页
- `storage`：存储用户设置
- `<all_urls>`：允许在所有网页上运行扩展

## 如何使用

1. 点击浏览器工具栏中的扩展图标打开弹出界面
2. 切换「深色模式」开关开启/关闭深色模式
3. 切换「阅读模式」开关开启/关闭阅读模式
4. 使用「字体大小」滑块调节网页字体大小
5. 设置会自动保存，下次打开浏览器时保持一致
6. **高级功能**：
   - **智能去水印**：切换开关自动隐藏网页水印和版权标签
   - **网页净化**：切换开关移除弹窗、推广内容和登录遮罩
   - **强制复制**：切换开关解除网站的复制和右键限制
   - **视频增强**：切换开关为网页视频添加倍速控制和画中画功能
   - **滚动平滑**：切换开关开启平滑滚动和自动阅读模式
   - **夜间模式增强**：切换开关启用智能深色主题
7. **AdGuard 集成**：
   - 查看 AdGuard 安装状态和运行状态
   - 点击「打开 AdGuard 助手」按钮启动 AdGuard 助手
   - 扩展会自动监听 AdGuard 拦截事件
   - 与 AdGuard 共享过滤状态
