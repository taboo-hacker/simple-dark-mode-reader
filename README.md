# Simple Dark Mode & Reader

一个轻量级的 Chrome 浏览器扩展，提供深色模式、阅读模式和多种网页增强功能，让您的浏览体验更加舒适和高效。

## 功能特性

- **深色模式**：一键开启/关闭网页深色模式，支持多种深色模式档位，智能适配各类网站
- **阅读模式**：净化阅读模式，隐藏广告和干扰元素，优化阅读体验
- **字体大小调节**：可调节网页字体大小，记忆用户设置
- **智能去水印**：隐藏常见网站的水印、版权标签
- **网页净化**：自动移除弹窗、推广、登录遮罩
- **强制复制**：解除网站禁止复制、禁止右键限制
- **视频增强**：网页视频支持倍速、全屏、画中画
- **滚动平滑**：开启平滑滚动与自动阅读模式
- **隐私与去跟踪**：清除URL中的跟踪参数，隐藏Cookie提示，禁止不必要的媒体权限请求
- **AdGuard 集成**：检测 AdGuard 是否安装并运行，打开 AdGuard 助手，监听 AdGuard 拦截事件，与 AdGuard 共享过滤状态（未实现）

## 安装方法

1. 克隆或下载本仓库到本地
2. 在 Chrome 浏览器中打开 `chrome://extensions/`
3. 启用 "开发者模式"
4. 点击 "加载已解压的扩展程序"
5. 选择本仓库的根目录
6. 扩展将被加载到浏览器中

## 如何使用

1. **深色模式**：
   - 点击扩展图标，在弹出的面板中切换 "深色模式" 开关
   - 选择 "深色模式档位" 调整深色模式效果
   - 点击 "添加到白名单" 将当前网站添加到白名单
   - 点击 "一键还原" 恢复网站原生主题

2. **阅读增强**：
   - 切换 "阅读模式" 开关，净化页面内容
   - 调整 "字体大小" 滑块，改变网页字体大小
   - 切换 "强制复制" 开关，解除网站复制限制
   - 切换 "滚动平滑" 开关，开启平滑滚动效果

3. **隐私净化**：
   - 切换 "清除跟踪参数" 开关，自动清除URL中的跟踪参数
   - 切换 "隐藏Cookie提示" 开关，自动隐藏Cookie同意提示
   - 切换 "禁止媒体权限" 开关，阻止网站请求摄像头和麦克风
   - 切换 "智能去水印" 开关，隐藏网页水印
   - 切换 "网页净化" 开关，移除弹窗和干扰元素

4. **视频工具**：
   - 切换 "视频增强" 开关，为网页视频添加倍速控制和画中画功能

7. AdGuard 集成（未实现）
   - 查看 AdGuard 安装状态和运行状态
   - 点击「打开 AdGuard 助手」按钮启动 AdGuard 助手
   - 扩展会自动监听 AdGuard 拦截事件
   - 与 AdGuard 共享过滤状态

## 技术实现

- **Manifest V3**：使用最新的 Chrome 扩展开发规范
- **CSS 注入**：通过注入 CSS 实现深色模式和阅读模式
- **Chrome 存储 API**：保存用户设置和网站特定配置
- **Chrome 脚本 API**：在网页中执行脚本，实现各种增强功能
- **响应式设计**：适配不同屏幕尺寸
