# Simple Dark Mode & Reader

一个功能强大的 Chrome 浏览器扩展，集成智能深色模式、阅读净化、视频增强、隐私安全和实用工具，让您的浏览体验更加舒适、高效和安全。

## ✨ 功能特性

### 🌙 深色模式
- **智能深色模式**：自动检测网站原生主题，同步开关状态
- **多档位选择**：标准深色、纯黑护眼、柔和深色三档可选
- **深色增强**：开启后自动打开深色模式，优化对比度和亮度
- **护眼黄底**：切换到暖黄色背景，减少蓝光伤害
- **网站白名单**：支持添加不启用深色模式的网站
- **一键还原**：快速恢复网站原生主题

### 📖 阅读净化
- **专注阅读模式**：隐藏广告、侧边栏、社交按钮等干扰元素
- **自动滚屏**：自动向下滚动页面，解放双手阅读
- **平滑滚动**：开启流畅的滚动效果
- **字体调节**：12-24px 字体大小可调
- **行距调节**：1.2-2.0 行距可调
- **间距调节**：0-5px 字间距可调
- **解除复制限制**：强制解除网站的复制、选中、右键限制
- **复制正文**：一键复制页面正文内容（不含广告）
- **复制链接**：一键复制页面所有链接

### 🎬 视频工具
- **视频增强**：启用视频控制增强
- **倍速播放**：0.25x - 4x 倍速可调
- **跳过片头广告**：自动跳过视频前广告
- **禁止自动暂停**：防止视频被自动暂停
- **画中画模式**：一键开启视频画中画
- **网页全屏**：视频网页全屏播放

### 🔒 隐私安全
- **清除跟踪参数**：自动清理 URL 中的 utm_source、fbclid、gclid 等跟踪参数
- **隐藏 Cookie 提示**：自动隐藏烦人的 Cookie 同意弹窗
- **禁止媒体权限**：阻止网站获取摄像头、麦克风权限
- **防指纹追踪**：伪装浏览器指纹，防止追踪

### 🛠️ 实用工具
- **页面净化**：一键移除广告、弹窗、悬浮按钮、二维码等
- **屏蔽弹窗**：阻止页面弹窗和跳转
- **禁止自动刷新**：阻止页面自动刷新和跳转
- **关闭 GIF 动画**：隐藏页面中的 GIF 图片
- **导出 PDF**：将当前页面导出为 PDF
- **长截图**：截取完整网页（需要额外权限）
- **定时刷新**：30秒/1分钟/5分钟/10分钟定时刷新
- **切换 UA**：快速切换手机/电脑 User-Agent

## 📦 安装方法

### 本地加载使用
本扩展未上架到应用商店，仅支持本地加载使用：
1. 下载本仓库代码到本地
2. 打开 Chrome 浏览器，访问 `chrome://extensions/`
3. 开启右上角的"开发者模式"
4. 点击"加载已解压的扩展程序"
5. 选择本仓库的根目录
6. 扩展将被加载到浏览器中

## 🚀 使用方法

### 快速开始
1. 点击浏览器工具栏上的扩展图标
2. 在弹出的面板中切换各项功能开关
3. 所有设置会自动保存并应用到当前网站

### 深色模式
- 打开"深色模式"开关，页面立即变为深色主题
- 选择"模式档位"调整深色效果强度
- 开启"深色增强"获得更好的对比度
- 开启"护眼黄底"切换到暖黄色背景

### 阅读优化
- 开启"专注阅读"隐藏页面干扰元素
- 开启"自动滚屏"让页面自动向下滚动
- 调节"字体"、"行距"、"间距"获得最佳阅读体验
- 点击"复制正文"一键复制文章内容

### 视频增强
- 开启"视频增强"启用视频控制
- 调节"倍速"滑块改变播放速度
- 点击"画中画"或"网页全屏"按钮
- 开启"跳过片头广告"自动跳过广告

### 隐私保护
- 开启"清除跟踪参数"自动清理 URL
- 开启"隐藏 Cookie 提示"屏蔽弹窗
- 开启"禁止媒体权限"保护隐私
- 开启"防指纹追踪"防止被追踪

### 实用工具
- 开启"页面净化"一键清理页面
- 开启"屏蔽弹窗"阻止烦人弹窗
- 选择"定时刷新"自动刷新页面
- 选择"切换 UA"模拟不同设备

## 🛠️ 技术实现

- **Manifest V3**：使用最新的 Chrome 扩展开发规范
- **Content Scripts**：在网页上下文中执行脚本
- **CSS 注入**：通过注入 CSS 实现样式修改
- **Chrome Storage API**：保存用户设置和网站特定配置
- **Chrome Scripting API**：在网页中执行脚本
- **响应式设计**：适配不同屏幕尺寸

## 🌐 浏览器支持

- Chrome 88+（支持 Manifest V3）
- Edge 88+（基于 Chromium 的 Edge）
- 其他基于 Chromium 的浏览器
